# Código de conducta

Adaptación breve del [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## Nuestro compromiso

Quien participa en Latido —issues, pull requests, revisiones y cualquier otro
canal— se compromete a que participar sea una experiencia libre de acoso para
todo el mundo, con independencia de edad, complexión, discapacidad visible o
invisible, etnia, características sexuales, identidad y expresión de género,
nivel de experiencia, educación, nivel socioeconómico, nacionalidad, apariencia
personal, raza, religión, orientación sexual o identidad sexual.

## Comportamiento esperado

- Tratar a las demás personas con respeto y empatía.
- Dar y aceptar críticas técnicas centradas en el código y en las decisiones, no
  en quien las toma.
- Reconocer los errores, pedir disculpas y aprender de ellos.
- Priorizar lo que es mejor para el proyecto y para quien lo usa.

## Comportamiento inaceptable

- Comentarios sexualizados, insultos, ataques personales o políticos, y
  provocaciones sostenidas.
- Acoso público o privado, y publicar información privada de terceros sin su
  permiso.
- Trollear, desviar discusiones de forma deliberada o interrumpir el trabajo
  ajeno.
- Publicar en un issue, un pull request o un comentario la prueba de un fallo de
  seguridad antes de que haya arreglo.

## Ámbito

Aplica a los espacios del proyecto (repositorio, issues, pull requests) y a
cualquier espacio donde alguien represente al proyecto.

## Aplicación

Quien mantiene el proyecto (`.github/CODEOWNERS`) es responsable de aclarar y
hacer cumplir estas normas, y puede editar, eliminar o rechazar comentarios,
commits, issues y pull requests que no las cumplan, explicando el motivo cuando
proceda. Las sanciones van desde un aviso privado hasta la expulsión temporal o
permanente del proyecto.

Para informar de un problema: escribe a
`smouj@users.noreply.github.com`. Todas las quejas se revisan con prontitud y
equidad, y la identidad de quien informa se respeta.
